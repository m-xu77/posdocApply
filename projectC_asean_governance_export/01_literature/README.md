# 01 · Literature

The literature review is organized around the five intellectual pillars the project needs to stand on. Each pillar has its own `.md` file with annotated bibliography (form: 1-paragraph summary + extracted contribution + how this project uses it).

| Pillar | File | Why this pillar |
|--------|------|------------------|
| 1 | `pillar_1_policy_diffusion.md` | Theoretical mechanism for why frames travel |
| 2 | `pillar_2_china_aid_bri_gdi.md` | Empirical landscape on what China's outward engagement looks like |
| 3 | `pillar_3_china_asean.md` | Region-specific context for CLMV |
| 4 | `pillar_4_text_as_data_llm.md` | Methods baseline; what's been done with NLP on policy texts |
| 5 | `pillar_5_comparative_donor_discourse.md` | DAC-vs-SSC discourse anchor for the comparison corpus |

All citations consolidated in `bibtex/full.bib` as the project grows.

## Working principles

- **No citation without a use-claim**: every reference in a pillar file states *how* this project will use it (background framing / contested-claim anchor / method precedent / counter-example).
- **Bilingual coverage**: Chinese-language scholarship (中国对外援助 / 国际发展合作) is read alongside English. Citations include Chinese titles.
- **Read for argument, not for completeness**: target 30–50 carefully read references per pillar. A 200-reference dump is not the goal.
