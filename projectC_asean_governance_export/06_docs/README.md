# 06 · Docs

Reference documentation for the repo. Three documents at minimum:

- `codebook.md` — frame-dictionary codebook + extraction-output codebook.
- `pipeline_doc.md` — operator manual for the pipeline (how to run, in what order, what each artifact means).
- `reproducibility.md` — environment, seeds, hashes, prompts, model versions.
- `adjudication_protocol.md` — referenced from `00_design/04_methodology.md` Stage 5.

These three plus the pre-registered design docs in `00_design/` are sufficient for a third party to replicate the study.
